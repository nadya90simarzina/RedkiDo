# Good Example

## Input

Проанализируй идею: "ИИ-ассистент должен быть не инструментом продуктивности, а средой для мышления".

## Expected Behavior

Use the skill to produce the nine requested sections: surface meaning, key ambiguities, conceptual cores, fragments and tensions, hidden assumptions, broader systems, non-obvious implications, reconstructed idea, and final synthesis.

The response should extract internal logic, avoid repeating the same insight across sections, and rank especially novel or useful implications when relevant.

## Must Not

Do not turn the request into a generic product plan, marketing copy, or implementation roadmap unless the user separately asks for that.
